# Security credits

People who found a security bug in Revel and told us about it first.

There is no bug bounty — see [the disclosure policy](https://revel.chat/security),
or [`docs/34-security-disclosure.md`](docs/34-security-disclosure.md) for the
reasoning behind it. This file is the credit half of that
promise, and it is a file rather than a page so that adding a name is one pull
request rather than a website deploy.

Names go in by whatever name the reporter gives us, or not at all if they would
rather not be listed. Anonymous is a normal choice and not a lesser one.

## Reported

*Nobody yet. This is not a boast — the app has not shipped, so there has been
nothing to report against. The file exists now so that the first person to find
something is credited on the day they report it, rather than after somebody
remembers to build a place to put them.*
