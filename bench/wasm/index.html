revel-crypto, in a browser

The same group-scaling benchmark as cargo run --release --example bench, run against the wasm build. docs/31 measured MLS on a native laptop CPU; this is what the numbers look like on the machine that actually has to do it. Ratios matter more than absolutes — the point is the gap between this table and the native one.

Two things this does not measure. Cold start on a real connection — the download is a fixed cost paid once per version and is reported above as a size, not a time, because that depends on someone's network rather than this machine. Concurrency — every call here runs on the main thread, which is not where a shipped client should put a 2,000-leaf commit.
