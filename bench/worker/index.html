Is the main thread free?

The same workload twice — admit N members to a group in one batched commit — once with the crypto on the main thread and once through @revel/crypto's Worker. The column that matters is the third one: how long the main thread went without being able to run anything, which is how long the app would have been frozen.

Both runs load their own copy of the wasm — a Worker cannot share the main thread's instance, and that is the cost of the split: one more module instantiation, measured at 2–5 ms in docs/31 §5.

Why two Worker rows. On a freshly loaded page the Worker takes about five times as long as the main thread at identical work, and a second run in the same page matches it exactly. It is not scheduling, not warmup, and not "the first Worker" — see docs/31 §6 for what has been ruled out. Both rows are shown because hiding the slow one would hide the thing a person actually hits first. ?warm=8000 sets the warmup.
